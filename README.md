### Repository policy

- Every public repo explains what it does, how to run it, what's verified, and what's intentionally local-only.
- README claims stay evidence-backed: install commands, test commands, CI status, and demo links must match reality.
- Hackathon repos keep the submission commit tagged and the final state clean — no half-merged branches on main.
- No secrets, no personal transcripts, no local paths in public code.
